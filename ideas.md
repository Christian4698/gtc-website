# Brainstorming Design - General Tech Consult

## Contexte
Site web professionnel pour un cabinet technologique premium (GTC) spécialisé en développement logiciel, analyse de données et formation Excel. Objectif : générer des clients, montrer expertise, rediriger vers contact WhatsApp.

Palette imposée : #0B3C5D (bleu principal), #072A40 (bleu foncé), #145DA0 (bleu secondaire), blanc, noir.

---

## Approche 1 : Minimalisme Géométrique Futuriste
**Probabilité : 0.08**

### Design Movement
Bauhaus moderne + Cyberpunk minimaliste

### Core Principles
1. **Géométrie stricte** : Lignes épurées, angles nets, grilles invisibles
2. **Espace blanc dominant** : Respiration maximale entre éléments
3. **Contraste fort** : Bleu foncé (#072A40) vs blanc pur, sans demi-teintes
4. **Asymétrie intentionnelle** : Éléments décalés pour créer dynamisme sans chaos

### Color Philosophy
- **Fond** : Blanc pur (#FFFFFF) avec sections en bleu foncé (#072A40)
- **Accents** : Bleu principal (#0B3C5D) pour les CTA, bleu secondaire (#145DA0) pour les hover
- **Intention** : Créer une sensation de confiance, modernité et clarté absolue

### Layout Paradigm
- **Hero** : Titre massif à gauche, espace blanc à droite (70/30 split)
- **Sections** : Alternance fond blanc/bleu foncé avec décalage horizontal des contenus
- **Grille invisible** : Colonnes asymétriques (3-5-4 ou 2-8-2)
- **Pas de centrage** : Tout aligné à gauche ou à droite

### Signature Elements
1. **Lignes géométriques** : Traits bleu foncé horizontaux/verticaux comme séparateurs
2. **Circuits stylisés** : Icônes minimalistes en wireframe (pas de remplissage)
3. **Carrés/rectangles** : Utilisés comme cadres autour de contenu important

### Interaction Philosophy
- **Hover** : Changement couleur bleu principal (#0B3C5D) + léger décalage (-2px)
- **Clic** : Transition 0.2s, aucune animation excessive
- **Focus** : Bordure bleu secondaire (#145DA0) 2px

### Animation
- Entrée au scroll : Éléments qui glissent depuis le bas (50px) avec fade-in (0.6s)
- Hover boutons : Changement couleur + scale(1.02) uniquement
- Pas d'animations continues (pas de floating, pas de pulse)

### Typography System
- **Display** : Poppins Bold 700 (48-64px) pour titres
- **Body** : Inter Regular 400 (16px) pour texte courant
- **Hiérarchie** : Bold pour sous-titres (20-24px), Medium pour labels

## Approche 2 : Élégance Organique Tech
**Probabilité : 0.07**

### Design Movement
Néomorphisme doux + Tech-organic (fusion nature/technologie)

### Core Principles
1. **Courbes fluides** : Coins arrondis (16-24px), formes organiques
2. **Dégradés subtils** : Transitions douces bleu foncé → bleu principal
3. **Profondeur douce** : Ombres multiples (soft shadows) plutôt que bordures
4. **Texture légère** : Grain subtil ou pattern géométrique en arrière-plan

### Color Philosophy
- **Fond** : Gris très clair (#F5F7FA) ou blanc avec gradient bleu très subtil
- **Cartes** : Blanc avec ombre douce (0 4px 12px rgba(11, 60, 93, 0.08))
- **Accents** : Bleu principal (#0B3C5D) avec dégradé vers bleu secondaire (#145DA0)
- **Intention** : Sensation premium, accessible, moderne sans être agressif

### Layout Paradigm
- **Hero** : Image abstraite (circuits organiques) en arrière-plan avec overlay bleu foncé semi-transparent
- **Sections** : Cartes arrondies flottantes avec ombres, disposées en grille asymétrique
- **Conteneurs** : Padding généreux (32-48px), border-radius 16-20px

### Signature Elements
1. **Cartes flottantes** : Ombres multiples pour effet de profondeur
2. **Dégradés bleu** : De #0B3C5D à #145DA0 sur certains éléments
3. **Circuits organiques** : Icônes avec courbes, pas de lignes droites

### Interaction Philosophy
- **Hover** : Ombre augmente (0 8px 24px), scale(1.03), couleur s'éclaircit légèrement
- **Clic** : Transition 0.3s, feedback haptique visuelle
- **Focus** : Anneau bleu secondaire (#145DA0) avec glow subtil

### Animation
- Entrée au scroll : Fade-in + slide-up (30px) avec ease-out (0.7s)
- Hover cartes : Ombre augmente + scale(1.03) + couleur s'éclaircit
- Boutons : Pulse subtil au chargement (opacity 0.8 → 1)

### Typography System
- **Display** : Playfair Display Bold 700 (48-64px) pour titres (élégance)
- **Body** : Lato Regular 400 (16px) pour texte (lisibilité)
- **Accents** : Montserrat SemiBold 600 pour labels/CTAs

## Approche 3 : Minimalisme Corporatif Strict + Icônes Circuits
**Probabilité : 0.09**

### Design Movement
Corporate modernisme + Swiss style (grille stricte, typographie épurée)

### Core Principles
1. **Grille 12 colonnes** : Alignement parfait, pas d'exceptions
2. **Typographie sans-serif** : Uniquement Inter, poids 400/500/600/700
3. **Espace régulier** : Multiples de 8px (8, 16, 24, 32, 40, 48px)
4. **Icônes circuits** : Omniprésentes, style ligne (stroke) 2px, couleur bleu principal

### Color Philosophy
- **Fond** : Blanc pur (#FFFFFF)
- **Sections alternées** : Blanc et gris très clair (#F5F7FA)
- **Texte** : Noir profond (#0A0A0A) pour contraste maximal
- **Accents** : Bleu principal (#0B3C5D) pour CTA, bleu secondaire (#145DA0) pour hover
- **Intention** : Professionnalisme absolu, confiance, clarté

### Layout Paradigm
- **Sections** : Largeur max 1280px, centrées, padding 48px horizontal
- **Grille** : 3 colonnes pour services, 2 colonnes pour features
- **Hiérarchie** : Titres grands (48px), sous-titres (24px), corps (16px)

### Signature Elements
1. **Icônes circuits** : Utilisées partout (services, features, benefits)
2. **Lignes horizontales** : Séparation entre sections (1px, couleur gris clair)
3. **Badges** : Petits carrés bleu foncé avec texte blanc pour labels

### Interaction Philosophy
- **Hover** : Couleur bleu principal (#0B3C5D), aucun scale
- **Clic** : Feedback visuelle immédiate (0.15s)
- **Focus** : Bordure bleu secondaire (#145DA0) 2px

### Animation
- Entrée au scroll : Fade-in simple (0.5s), pas de mouvement
- Hover boutons : Changement couleur bleu principal (#0B3C5D) + underline
- Pas d'animations complexes (priorité à la clarté)

### Typography System
- **Display** : Inter Bold 700 (48-56px) pour titres
- **Body** : Inter Regular 400 (16px) pour texte
- **Labels** : Inter SemiBold 600 (14px) pour CTAs et badges

---

## Décision Finale

**Approche sélectionnée : Minimalisme Géométrique Futuriste**

Cette approche combine :
- ✅ Modernité et tech-forward (circuits, géométrie)
- ✅ Professionnalisme premium (contraste fort, asymétrie intentionnelle)
- ✅ Clarté maximale (espace blanc, pas de distraction)
- ✅ Performance perceptuelle (animations légères, pas de surcharge)
- ✅ Alignement avec palette imposée (bleu foncé dominant, blanc pur)

Cette philosophie guidera chaque décision : composants, typographie, espacement, animations, et interactions.
